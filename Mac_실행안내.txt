Crawler Hub — macOS 실행 안내

1. ZIP을 압축 해제합니다. Crawler_Hub_Mac.command와 app, brands가 같은 폴더에 있어야 합니다.
2. Python 3.10 이상이 필요합니다. Python이 없으면 https://www.python.org/downloads/macos/ 에서 설치합니다.
3. Crawler_Hub_Mac.command를 더블클릭합니다. Terminal 창에서 필요한 패키지를 준비한 뒤 브라우저가 열립니다.
4. 실행 중에는 Terminal 창을 유지합니다. 종료하려면 실행 창에서 Control+C를 누릅니다.

실행 권한이 사라진 경우
공유폴더 전송이나 압축 해제 과정에서 실행 권한이 유지되지 않을 수 있습니다.
Terminal에서 아래처럼 입력합니다. 경로 부분은 실제 파일 경로로 바꿉니다.

chmod +x "/실제/폴더/Crawler_Hub_Mac.command"
"/실제/폴더/Crawler_Hub_Mac.command"

Playwright 브라우저가 필요한 경우
Terminal에서 다음처럼 실행합니다.

"/실제/폴더/Crawler_Hub_Mac.command" --install-browser

데이터와 호환성
- 기본 작업 이력·설정·가상환경: ~/.local/share/CrawlerHub
- 결과 폴더/파일 열기는 Finder와 기본 연결 앱을 사용합니다.
- 더아이잗 구글 검색 경유판은 설치된 Mac용 Chrome 또는 Playwright Chromium을 사용합니다.
- 웨스트우드의 Windows OCR 자동 색상 인식은 Mac에서 사용할 수 없습니다. 저장한 사진은 허브에서 수동으로 매핑합니다.
- Mac 실기기에서 전체 브랜드 수집은 별도 확인이 필요합니다.
