색상 매핑 저장 속도 개선

옵션의 선택 저장/Enter는 선택 순서를 즉시 반영하고 브라우저 localStorage에 임시 보관합니다. 이 품번의 모든 활성 옵션(수동 상세 옵션 포함)을 선택하면 서버에 한 번에 저장한 뒤 다음 미완료 품번으로 이동합니다. 중간 저장하고 나가기, 최종 완료, 옵션 변경/삭제, AM 재적용 전에도 대기 중인 확정 선택을 서버에 저장합니다. 미확정 사진 선택은 중간 저장/완료 시 함께 저장합니다.

서버는 전체 요청을 검증한 뒤 한 번의 atomic_json으로 저장합니다. 일부 옵션이 잘못되거나 다른 창에서 수정한 경우에는 부분 저장하지 않습니다. 응답에는 변경한 품번만 포함하며 AM 원본과 전체 사진 목록을 매번 전송하지 않습니다. 기존 수집 결과는 수정하지 않습니다.

같은 앱 주소/브라우저의 새로고침에서는 서버 리비전이 일치하는 임시 선택만 복원합니다. 다른 창에서 서버가 변경됐다면 오래된 임시 선택을 덮어쓰지 않습니다. PC 간 이동이나 브라우저 데이터 삭제 전에는 중간 저장하고 나가기를 사용합니다.

로컬 합성 데이터(344품번, 사진 4,128장, AM 옵션 6개/품번)의 한 품번 저장 비교: 기존 6회 0.721초/9,254,891바이트 응답, 개선 1회 0.094초/4,697바이트 응답. 실제 성능은 작업 크기 및 PC에 따라 다릅니다. 격리된 실제 앱/Chrome에서도 첫 옵션 서버 요청 0회, 마지막 옵션 1회, 새로고침 복원, 다음 품번 자동 이동을 확인했습니다.
