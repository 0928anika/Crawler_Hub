# 패션플러스 품목번호: 상위/하위 입력

상위 번호와 하위 번호 모두 연결된 상위 상품의 전체 옵션을 수집합니다. 숫자 또는 공식 상품 URL을 입력합니다.
하위 페이지에 선언된 상위 옵션 API 경로와 공식 Product SKU를 대조하고, 상위 상품 응답의 현재 옵션 ID와도 대조합니다.
품절 등으로 입력 하위가 현재 옵션 목록에서 빠졌어도 상위 연결·SKU가 일치하면 수집합니다. 상품명에서 SKU를 추정하지 않습니다.
상위품목ID는 실제 상위 번호, 입력품목ID는 사용자가 입력한 번호, 하위품목ID는 하위 입력 시의 번호입니다.
엑셀 선두의 상위품목ID/품번 순서는 유지합니다. 하위 번호를 입력해도 상위 상품 전체 색상·사이즈를 사용하고
사진·상세·판매가·별도 정상가는 검증한 상위 상품에서 가져옵니다.
판매가는 기존 판매가 행 정책을 유지하며 쿠폰이 포함될 수 있는 옵션 _price는 원본 옵션에만 보존합니다.
상위가 여러 색상이면 하위 옵션이 하나라도 사진을 수동 매핑하여 다른 색상 사진의 자동 배정을 막습니다.

베이지/55·66, 판매가 289000(옵션 원문가격 242760은 원본 옵션에 보존). 같은 상위 번호를 입력하면 55/66 전체 사이즈가 유지됩니다.
