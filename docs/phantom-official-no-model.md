# 팬텀 공식 홈페이지 모델컷 제외

ID: phantom_official_no_model. 기존 phantom_official과 별도입니다.

공식 색상별 imageList 전체를 규격 검사 후 색상에 미리 연결합니다. 자동으로 모델 여부를 판정하지 않습니다. 매핑 화면에서 모델컷의 선택을 해제하고 색상별로 저장한 뒤 완료하세요. 검수하지 않은 옵션은 완료로 처리하지 않습니다.

상세페이지는 저장한 해당 색상의 사진 순서 + 공식 상품정보고시 + 사이즈 안내/실측표로 재구성합니다. 기존 goodsDescription 본문은 사용하지 않으며, 선택에서 제외한 모델컷은 상세에도 들어가지 않습니다. 없는 고시·사이즈표는 생략합니다. 추가이미지는 최대 9장, 상세는 선택한 사진을 모두 사용합니다.

공식 사이즈 측정 안내 그림 자체는 원본을 유지합니다. 그 안의 삽화를 자동 판별해 자르는 기능은 없습니다.

앱도 업데이트하고 재시작해야 URL 사진의 공식 사전 매핑과 색상별 상세 재구성이 적용됩니다. 기존 작업의 재시도 대신 새 크롤러로 새 작업을 시작하세요.
