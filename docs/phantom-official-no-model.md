# 팬텀 공식 홈페이지 모델컷 제외

ID: phantom_official_no_model. 기존 phantom_official과 별도입니다.

배지: 사진 제외 필요. 작업 이력·모니터·결과 검수의 사진 제외하기 버튼으로 엽니다. 이전 버전으로 수집한 작업도 ID로 인식하므로 재수집할 필요가 없습니다. 실패한 품번을 성공으로 바꾸거나 없는 사진을 만드는 기능은 아닙니다.

공식 색상별 갤러리 사진을 작업 전체의 하나의 갤러리로 보여줍니다. 왼쪽은 사용할 사진, 오른쪽은 쓰레기통입니다. 버릴 사진을 클릭하거나 드래그해 선택하고 Enter 또는 버리기를 누르세요. Esc는 양쪽 선택을 모두 취소합니다. 쓰레기통에서 선택해 복원할 수 있고 우클릭으로 확대할 수 있습니다. 품번·상품명·색상 검색도 지원합니다. 화면에 보이는 구간만 그려 사진이 많아도 DOM과 이미지 로딩이 몰리지 않습니다.

중간 저장하고 나가기는 제외 선택만 보관합니다. 기존 최종 엑셀은 바꾸지 않습니다. 최종 저장 · 결과에 적용을 누르면 한 번에 엑셀과 상세페이지를 재구성합니다. 색상별로 따로 저장할 필요가 없습니다.

최종 상세페이지는 해당 색상에 남긴 사진 + 공식 고시 + 사이즈 안내/실측표입니다. 기존 goodsDescription 본문은 사용하지 않습니다. 색상의 사진을 전부 버리면 그 색상은 최종 결과에서 제외되지만 원본과 연결 정보는 보존되므로 복원할 수 있습니다. 추가이미지는 최대 9장, 상세는 남긴 사진을 모두 사용합니다. 고시·사이즈표가 없으면 생략하며 공식 사이즈 측정 삽화는 원본을 유지합니다.

results.jsonl과 입력·원본 사진 URL은 수정하지 않습니다. 제외 목록은 color_mapping.json의 별도 필드에 저장합니다. 저장 전 이전 매핑 파일과 최종 엑셀을 작업 폴더의 photo-review-backups/시각 폴더에 백업합니다. 내보내기 실패 시 이전 상태와 엑셀로 되돌립니다.

앱 업데이트 후 재시작하면 기존 작업에서 바로 사용할 수 있습니다. 수집 중인 작업은 종료 후 사진을 검수하세요. 수집 중에는 앱을 강제로 재시작하지 마세요.
