# Windows 공개 develop 업데이트 v2

Git 설치·GitHub 로그인·토큰 없이 공개 develop을 받습니다. Python 3.10 이상이 필요합니다.

## 처음 설치 / 업데이트 도구 수동 교체

BAT와 저장소 tools/update_develop.py 파일을 같은 폴더에 두세요.
폴더 이름은 자유이며 설치 폴더 아래의 임의 하위 폴더에서도 상위 앱 위치를 자동으로 찾습니다.
단, 교체 대상인 app/brands 안에는 두지 마세요.

```text
Crawler_Hub/
  app/
  brands/
  Crawler_Hub_Windows.bat
  Crawler_Hub_Mac.command
  개발자전용/
    Crawler_Hub_Update_Windows.bat
    update_develop.py
```

기존 루트 BAT + tools/update_develop.py 배치도 호환됩니다.
앞으로 업데이트 프로그램 자체는 자동 교체하지 않습니다. 변경이 있으면 두 파일을 수기로
교체하세요. 구버전 프로그램도 이번에 한 번 수동으로 바꿔야 합니다.
폴더 숨김/이름 변경은 접근 제어가 아닙니다. 개발자만 사용하려면 별도 Windows 폴더 권한을
설정하세요. 특정 폴더 이름을 강제하지 않습니다.

## 업데이트 범위

- app/ 전체
- brands/ 전체
- Crawler_Hub_Windows.bat
- Crawler_Hub_Mac.command

위 네 항목만 교체합니다. tools/문서/프롬프트/테스트/개발용BAT/업데이트BAT를 추가하거나
교체하지 않습니다. 기존 파일도 임의 삭제하지 않습니다. 필요 없는 문서/프롬프트 등은
별도로 정리하세요. Python 보조 파일을 tools에 두고 사용 중이면 그 파일은 유지하세요.

## 사용 및 속도

앱 실행 콘솔을 종료하고 업데이트 BAT 실행 후 기존 앱 실행기로 다시 실행하세요.
브라우저 탭만 닫으면 서버가 남을 수 있습니다. 강제 종료하지 않습니다.
최신 커밋이 같고 로컬 앱/브랜드/실행기 내용도 그대로면 ZIP 다운로드와 교체를 생략합니다.
로컬 파일이 바뀌었으면 동일 커밋이어도 다시 받아 복구합니다.
새 커밋은 SHA로 고정한 GitHub ZIP을 내려받고 필요한 파일만 해제·검증합니다.
ZIP 자체는 전체 저장소이므로 새 커밋의 다운로드 속도는 네트워크 환경 영향을 받습니다.
이전 도구의 상태에는 파일 지문이 없으므로 새 버전 최초 실행에는 다운로드가 필요할 수
있습니다. 다음 동일 커밋부터 빠른 경로를 사용합니다.

## 보존 / 복구

기존 작업·설정·결과·가상환경(CRAWLER_HUB_HOME 또는 LOCALAPPDATA/CrawlerHub)은 유지합니다.
교체 대상 밖의 로컬 파일도 유지합니다. 교체 대상 안에 사용자 데이터가 있으면 중단합니다.
기존 소스는 .crawler-update-backups/<시각_커밋>/에 보관하고 중간 실패 시 복구합니다.
로컬에만 추가한 브랜드는 공식 최신 폴더로 교체되며 이전 파일은 백업에 남습니다.
develop에서 삭제한 브랜드는 새 목록에서도 제거됩니다. 기존 작업의 실행 사본은 유지합니다.
수정 크롤러는 업데이트 후 새 수집 작업으로 확인하세요.
동시 업데이트는 차단합니다. 강제 종료 후 잠금이 남으면 프로세스 종료를 확인한 뒤
.crawler-update.lock을 지우고 재시도하세요.

Git 개발 폴더는 실제 적용을 막습니다. 개발자는 git pull을 사용하세요.
BAT --check-only는 다운로드/검증만 수행하며 Git 폴더에서도 가능합니다.
주기 실행/앱 시작 시 자동 실행은 등록하지 않습니다.
공개 저장소만 지원하며 다운로드/검증 실패 시 적용하지 않습니다.
SHA/해시 검증은 코드 서명 또는 회사 승인된 릴리스라는 의미는 아닙니다.
