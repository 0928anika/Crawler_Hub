# 아디다스 공식 홈페이지

기존 API 수집을 유지하고 API·축약 상품 주소가 403/429로 막히면 기존 Chrome의 공식 상품 탭을 사용합니다. 정상 상품 주소에는 상품명 경로가 포함될 수 있으므로 /품번.html만으로 상품 존재 여부를 판단하지 않습니다.

Chrome에서 요청 품번의 전체 상품 주소가 이미 열려 있으면 그대로 읽습니다. 다른 품번은 공식 검색에서 해당 품번으로 끝나는 adidas.co.kr 상품 링크를 찾아 들어갑니다. 다른 도메인 링크와 추천 상품의 다른 품번은 사용하지 않습니다.

최신·기존 __NEXT_DATA__에서 정확한 상품코드의 데이터를 찾고, 없으면 같은 Chrome 세션의 공식 상품 API를 읽습니다. 고시·사이즈표·가격·이미지는 기존 수집 규칙을 적용합니다. Chrome 세션에서도 403이면 접근 제한으로 명시하며 상품 없음으로 바꾸지 않습니다.

Chrome 자체 원격 디버깅 연결 승인은 사용자가 직접 해야 합니다. 브라우저·로그인 프로필을 새로 만들지 않고 기존 Chrome을 유지합니다. 다른 Chrome 사용 크롤러와 동시 실행은 제한됩니다.

2026-11-25 기존 Chrome에서 KS4159를 실제 수집했습니다. 코듀로이 푸퍼 재킷 / Aurora Coffee / XS~4XL / 판매가·정상가 각 259000원, 대표·추가 사진, 고시, 사이즈표가 포함된 XLSX 생성 확인. 축약 주소의 페이지 표시와 달리 같은 Chrome 세션의 공식 상품 API는 정상 응답했으며, API의 canonical 전체 상품 주소를 결과에 사용합니다. 최초 연결 후 품번마다 연결 승인을 반복하지 않습니다.

바코드는 선택 수집 항목입니다. 선택하면 사이즈도 자동 선택되어 variation_list의 각 size·gtin 조합을 한 행씩 출력합니다. 같은 품번·색상의 이미지와 상세는 재사용합니다. 미선택 시 기존처럼 색상당 한 행에 사이즈를 쉼표로 합칩니다. GTIN이 없거나 형식이 확인되지 않는 사이즈도 제외하지 않고 바코드를 공백으로 남겨 검수에서 미수집으로 표시합니다. GTIN은 문자열로 기록해 앞자리 0을 유지합니다. 앱도 업데이트 후 재시작해야 새 항목이 표시되며 기존 작업 결과는 변경하지 않습니다.
