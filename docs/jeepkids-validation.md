# 지프키즈 공식몰 크롤러

2026-11-10 실제 조사 및 검증. 브랜드 ID `jeepkids_official`, 소스 `공식 홈페이지`, 분류 `아동복`.

## 수집 근거

- 사용자 지정 jeepwear.co.kr만 수집한다. 첨부에 같이 있던 goodwearmall.com의 다른 품번은 사용하지 않는다.
- 공식 `/product/search.html?keyword=...` 검색의 모든 페이지/상품을 순회한다. 상품명 마지막 괄호의 전체 품번을 기본 품번 9자리와 색상코드 2자리로 분리하고 기본 품번을 정확히 대조한다. 공식 breadcrumb에 KIDS가 있는지도 확인한다.
- 상품명에서 전체 품번을 제거하고 원본 상품명은 별도 열에 보존한다. 공식 기본 정보의 색상/컬러 필드가 있으면 사용한다. 샘플에는 별도 색상명 텍스트가 없어 KH/BK/ID만 제공하며 코드 번역표나 사진 색감으로 이름을 추정하지 않는다.
- 색상별 독립 상품 페이지의 공식 JSON-LD ProductGroup.hasVariant.image가 실제 big 원본 URL을 제공한다. 화면 small 원본과는 해시가 다르므로 URL 경로를 임의 변조하지 않는다. 동일 상품명의 ProductGroup만 읽어 다른 색상의 공통 사진을 섞지 않는다.
- 공개 이미지 GET/실제 파일 형식/500px/10MB/보수적 비율/제외 신호 검사와 해시 중복 제거 후 대표·추가 5슬롯 구성. 샘플은 색상별 원본이 한 장이라 동일 컷을 추가 슬롯에도 반복하고 안내 로그를 남긴다.
- 사이즈는 공식 option의 전체 표시명이며 disabled/품절 옵션도 제외하지 않는다. 사이즈/추가이미지는 쉼표 한 줄로 저장한다.
- 판매가는 기본 정보 판매가 행의 공개 KRW 숫자다. 확인한 샘플에는 독립 정상가/소비자가 행이 없고 .custom은 0만 표시되어 정상가를 미지원으로 등록했다. 판매가 복사/할인율 역산을 하지 않는다.
- 상세는 공식 `#prdDetail .cont`의 NNEditor 상품 이미지 원본만 보존한다. 이미지 안 고시와 사이즈표를 별도 표로 만들지 않는다. 갤러리의 세로 비율 필터를 상세에 적용하지 않는다. 별도 사이즈가이드/고시 전용 요청은 없다.
- 선택한 사진만 독립 공개 GET으로 검사한다. Chrome의 자동 이미지/미디어/폰트 요청은 차단한다. worker 출력 잠금이 있을 때만 최대 3개 요청을 병렬 확인하며 구버전 Hub는 순차 방식으로 호환된다. 프로필/임시 파일은 ctx.output_dir 안에만 생성한다.

실제 UI에서의 전체 클릭 흐름, 샘플 밖 다중 검색 페이지 및 WING 상품 등록은 별도 검증 대상이다. 규칙 기반 사진 검사는 모든 합성 사진을 완벽히 인식하거나 등록 승인을 보장하지 않는다.
