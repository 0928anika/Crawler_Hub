# 블랙야크 공식 홈페이지 수집 검증

2026-11-10. `blackyak_official` / 블랙야크 / 공식 홈페이지. Level 1 자동 색상 매핑, 앱 공통 코드 변경 없음.

## 공식 식별 및 색상 연결

- 실제 검색 폼 `/blackyak/shop/search_result.php?search_str=품번`에서 상품 링크를 찾고 `.prd-desc__code-value` 전체 품번을 대조한다. 상품명에 브랜드명이 있는지는 필수 조건이 아니다.
- `1BYGJFV002FB`, `1BYGJFV002DY`는 기본 품번 `1BYGJFV002`와 실제 색상코드 `FB`, `DY`로 분리된다. 색상명은 `.prd-info__color-name`, 색상 링크는 `.prd-info__color-chip`에 있다. 현재 공개 검색·색상 링크는 FB/DY 2개이며, 고시의 색상 목록에만 있는 LIME OLIVE의 링크를 추측해 만들지 않는다.
- 입력 `1BYGJFV002`는 공개 전체 색상, `1BYGJFV002DY`, `1BYGJFV002_DY`, `1BYGJFV002-DY`는 지정 색상. 특정 색상은 전체 SKU로 공식 검색해 다른 색상 사진을 요청하지 않는다.
- 각 색상의 별도 pno를 확인한 `.prd-thumb__item[data-type=image]`만 사용한다. 숨겨진 D7~D12 등도 포함한다. 배너·추가 브랜드 이미지·리뷰·추천 영역은 제외한다.
- 원문 HTTP picweb 이미지에서 간헐적인 읽기 타임아웃을 관찰했다. 공식 색상칩에도 쓰는 동일 호스트/동일 경로의 HTTPS 원본을 실제 GET/해독 확인 후 사용한다. 파일명·확장자·해상도·사진 순번을 추측해 변경하지 않는다.

## 상세 HTML

요청에 따라 기존 상품컷 전체 + 상품정보제공고시 텍스트 + 사이즈 가이드 원본 표를 조합한다.

- 상품컷: 해당 색상 갤러리 원본 전체. 대표/추가와 별도로 상세만 선택해도 조회한다.
- 고시: `상품정보제공고시` 제목의 accordion 안 `dl`에서 항목/값을 순서대로 읽고 텍스트 문단으로 보존한다. 상품코드·소재·제조국·제조연월·연락처 등 원문 항목/값을 대조했다. 고시용 새 table은 만들지 않는다.
- 사이즈: 숨겨진 `.prd-modal-size__table table` 원문 표. 머리글·값·소수 표기·앞자리 0·rowspan/colspan 및 `단위 : 의류/용품(cm), 신발(mm)`를 보존한다. 재귀 렌더링으로 이벤트/스크립트를 제거하며 트리 삭제/unwrap을 하지 않는다.
- 소재/관리 설명·배송/교환/환불·공통 배너·추천·리뷰는 상세에 넣지 않는다. 고시/가이드가 없는 경우는 경고 후 해당 부분만 생략한다. 응답 지연 사진은 병렬 조회 이후 개별 재시도한다. 일부 사진이 계속 지연되면 확인된 상품컷과 원문 고시·표를 보존하고 누락 URL을 경고로 남긴다. 모든 상품컷을 확인하지 못한 상태에서 통신 오류가 남으면 실패로 기록한다.

## 선택 항목

- 사이즈는 `.prd-info__size-chip`의 전체 표시 옵션을 순서대로 쉼표 연결한다. 재고 0/disabled도 유지하며 `095`를 정수로 바꾸지 않는다.
- 판매가는 `.prd-info__price-current .prd-info__price-num`, 정상가는 독립 `.prd-info__price-original .prd-info__price-num`. `currency=원` 확인. 나의 혜택가/쿠폰가를 쓰지 않는다. 정상가 누락/0/형식 오류는 None 및 경고로 계속 진행한다.
- 카테고리는 공식 form의 `toss_cate_name`. 원본 상품명과 공식 전체 품번은 별도 추가 열로 보존한다.
- 미선택 갤러리/가격/사이즈/상세 전용 파싱과 요청은 실행하지 않는다. 상세만 선택하면 상품컷과 고시·가이드만 조립하고 갤러리 슬롯/옵션 사이즈를 수집하지 않는다.
