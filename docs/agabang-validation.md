# 아가방 공식몰 크롤러

검증일: 2026-11-09. ID `agabang_official`, 분류 `유아동 의류`, 소스 `공식 홈페이지`.

## 속도 개선 (agabang-2)

첫 검색 주소와 페이지 링크의 page=1을 같은 검색 페이지로 판정해 중복 조회를 제거했다. 선택된 대표/추가 후보와 실제 상세 이미지만 최대 3개 공개 요청으로 병렬 확인하고 검사 결과를 공유한다. 이벤트/브랜드/배송 이미지는 병렬 대상에도 넣지 않는다. 실행부의 EMIT_LOCK이 확인되는 경우에만 병렬로 처리하며 구버전 Hub는 안전하게 순차 처리한다. 공개 접근/실제 파일 검사를 생략하거나 타임아웃으로 성공 처리하지 않는다.

동일한 실제 Hub worker/전체 선택 비교: 01t721012 37.8초→28.0초, 01T71760176 39.4초→28.0초. 두 결과 모두 normal이며 엑셀 저장도 통과했다. 개선 후 이미지 응답/해독 확인에 20.7~21.8초가 걸렸으므로 총 시간은 사이트와 네트워크 상태에 따라 달라진다. 회귀 테스트 8개 통과.

## 수집 방식

- 공식 `https://agabangmall.com/product/search.html?keyword=...`의 전체 검색 페이지에서 상품 링크를 회수한다. 상품 기본 정보의 모델을 입력한 기본 품번과 정확히 대조하고 브랜드가 아가방인지 확인한다.
- 기본 모델은 9자리 (`01T721012`). 상품명 끝 전체 코드 (`01T72101293`)와 단일 색상 옵션 (`RED`)이 일치할 때 뒤의 숫자 2자리 (`93`)를 공식 색상코드로 보존한다. 다른 품번의 검색 결과는 제외하며 다색상 페이지를 단일 사진에 억지로 매핑하지 않는다.
- 기본 모델은 검색된 모든 색상, 전체 코드 또는 `_93` / `-93` 지정은 해당 색상만 수집한다. 대소문자는 구분하지 않으며 앞자리 0은 보존한다.
- 사이즈는 공식 `option_stock_data.option_value_orginal`의 색상/사이즈 연결에서 읽는다. 재고 0/품절이라는 이유로 제외하지 않는다.
- 판매가 `option_stock_data.option_price`와 정상가 `소비자가` 행은 독립 선택한다. 정상가가 없거나 0/잘못된 값/조회 예외이면 빈칸과 안내 로그만 남긴다. 사이즈별 판매가가 다르면 임의 최저가를 쓰지 않는다.
- 사진은 해당 단일 색상 상품의 `.imgArea` 중 공식 `big` 및 `extra/big` 경로에서만 읽는다. 리뷰/추천/상세 통짜를 대표나 추가 컷으로 사용하지 않는다. 공개 GET/실제 파일/500px/10MB/형식/비율과 제외 신호를 검사한다. 일반적인 자동 규칙이며 완전한 시각 인식/등록 승인 보장은 아니다.
- 상세는 `#prdDetail`에서 실제 상품 코드 이미지의 원본 URL만 보존한다. 이벤트·브랜드 소개·하단 공통 배너는 요청하지 않는다. 사용자가 요청한 대로 이미지 안 사이즈표/고시는 그대로 유지하고 별도 HTML 표를 만들지 않는다.
- Chrome은 페이지 구조 확인에 사용한다. 브라우저의 이미지/미디어/폰트 자동 요청은 차단하고 선택된 항목의 공개 이미지 검사만 별도로 수행한다. 임시 프로필은 `ctx.output_dir` 아래에 저장한다. 별도 사이즈가이드/고시 요청은 없다.

## 실제 Hub worker 검증

실제 `app/worker.py`의 JSON 이벤트 전달과 SDK Excel 저장을 사용했다.

| 입력 | 모델 | 색상 | 코드 | 사이즈 | 판매가 | 정상가 | 최종 검수 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 01t721012 | 01T721012 | RED | 93 | 90,100,110,120 | 49000 | 49000 | normal |
| 01T71760176 | 01T717601 | L/GREEN | 76 | 70,80,90 | 35000 | 35000 | normal |

각 상품의 공식 대표사진은 600×600이며 갤러리에서 확인된 독립 컷이 한 장이라 해당 컷을 추가 5슬롯에도 사용하고 안내 로그를 남겼다. 존재하지 않는 다른 각도 사진을 만들지 않았다. 상세 이미지 원본 URL 보존, 공통 배너 제외, 별도 table 생성 없음, 한 줄 사이즈/추가 URL, 실제 상품 링크도 검사했다.

실제 검증 상품 링크:

- https://agabangmall.com/product/detail.html?product_no=55628
- https://agabangmall.com/product/detail.html?product_no=55656

단위 테스트는 `python -m unittest discover -s tests -p test_agabang.py`. 실제 공식 HTML에서 필요한 공개 상품 필드만 줄여 저장한 fixture로 숫자 색상코드/앞자리 0, 다른 모델 제외, 옵션 사이즈 전체, 네 가지 가격 선택 조합, 정상가 누락/0/형식 오류/조회 예외, 미선택 전용 작업 금지, 상세 이미지/공통 배너 구분, 작은 이미지 탈락과 추가 5슬롯을 확인한다.

샘플은 검색 결과가 각각 1색상이었다. 실제 다색상/여러 페이지 검색 상품과 WING 업로드는 아직 별도로 검증하지 않았다. 상품 페이지 구조가 달라지면 명확히 실패로 남기며, 일부 색상이 실패해도 이미 완료한 색상 결과는 보존한다.
