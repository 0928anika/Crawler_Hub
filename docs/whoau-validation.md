# 후아유 공식 홈페이지 수집 검증

2026-11-10, `whoau_official` / `공식 홈페이지`.

- 사용자 품번 `WHMAG4V22U` 공식 검색 결과는 상품 5696 및 5692. 5696 상세 첫 이미지에 인쇄된 품번 WHMAG4V22U도 직접 확인했다. 품번이 HTML 텍스트에 없어 검색 결과 연결을 사용하며 OCR을 크롤러 의존성으로 추가하지 않았다. 다른 품번 전반을 검증한 것은 아니다.
- 공식 `ul[option_title=Color] li[option_value]`의 `link_image`로 색상 연결. 5696에는 33/76만 있고 60이 비어 있으므로 5692 옵션 링크로 보완한다. JSON-LD의 모든 색상이 같은 image를 갖는 문제를 관찰했으므로 그 image 배열은 갤러리에 사용하지 않는다.
- 실제 33 Oatmeal Melange와 76 Light Purple 원본을 열어 색상 연결과 단일 상품컷 확인. 갤러리는 개별 공개 원본 바이트 검사 후 저장, 추가 컷 부족 시 통과 컷만 반복한다.
- `ProductGroup.hasVariant`의 색상별 size는 품절 포함 S(090),M(095),L(100),XL(105). 독립 판매가 행 53,910, 소비자가 행 59,900.
- `#prdDetailContent`의 상품·사이즈·고시 원본 3장만 보존. 고시/사이즈표를 새 표로 만들지 않는다. 이미지 CDN은 실제 문서에 연결된 whoaukr 전용 cafe24.poxo.com과 item-imghub.eland.co.kr만 사용한다.
- 실제 Hub 워커와 Excel: 소문자 기본 품번 전체 3색상/3행 정상, 약 4.3초. `_60` 지정 색상 정상, 약 3.7초. `-76`도 실행 검증. 모든 결과 추가 이미지 5슬롯 쉼표 문자열, 상세 img 3장, table 생성 없음.
- 선택 항목을 모두 끈 경우 이미지/가격/사이즈/상세 전용 작업을 하지 않는 자동 테스트 포함. 실제 WING 업로드와 모든 품번에 대한 동작을 보장하는 검증은 별도다.


## 정식 혼합 매핑 (revision 2)

- 브랜드 ID와 소스명은 유지하고 `mapping_mode=manual`, `hybrid_mapping=true`로 등록한다. 공식 Color 옵션 연결 사진은 일반 결과 행으로 보존하며 미연결 개별 갤러리 사진만 `emit_unmapped`로 보낸다. 같은 이미지의 URL 별칭도 실제 바이트 해시로 제외한다.
- 사용자 확인에 따라 일부 색상 사진이 이미 연결된 상품도 나머지 미연결 모델컷을 수동 화면에 보낸다. 연결된 사진은 그 화면에 표시하지 않는다. 색상이 아예 연결되지 않은 상품도 수동 후보만 전달한다.
- 앱 SDK는 명시적 혼합 매핑 opt-in일 때 자동 행만 있는 실행도 정상 종료한다. 매핑 최종 저장/엑셀에는 자동 행을 보존하고 수동 사진을 같은 품번·색상 한 행으로 합친다. 자동 대표를 유지하며 추가는 통과 사진 5슬롯이다. 기존 수동 전용 브랜드 동작은 opt-in 없이 유지한다.
- 5600 상품의 `AC` 코드가 숫자 전용 정규식 때문에 거절되는 문제를 수정했다. 공식 영숫자 색상코드 두 자리를 그대로 보존하고 지정 입력도 허용한다.
- 5693의 `상세06.jpg`는 실제 공개 이미지지만 기존 `check_public_image` 기본 10MB 제한에 걸렸다. 갤러리 10,000,000바이트 정책은 유지하고 상세 조회만 별도 캐시와 64MiB 한도를 사용한다. 원본 이미지를 자르거나 URL을 바꾸지 않는다.

후아유·혼합 매핑·워커 이벤트·기존 수동 크롤러 관련 자동 검사 28개 통과. 미연결 전용 상품, AC, 원본 10MB 초과 상세, 자동 사진 URL 별칭 제외, 자동 전용 작업, 실패 행 제외, 저장 전후 Excel 보존을 포함한다. 상세 장수는 상품 페이지마다 다르며 WHKAG4T35U의 검색 첫 페이지 5602에는 원본 2장이 있어 이를 그대로 보존한다.

배포 시 혼합 매핑 지원 앱의 `crawler_sdk.py`, `color_mapping.py`, `tasks.py`도 함께 갱신하고 재시작해야 한다. 브랜드 JSON/Python만 이전 앱에 붙이는 것으로 앱의 혼합 최종 저장 기능이 추가되지는 않는다.
