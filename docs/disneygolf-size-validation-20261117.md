# 디즈니골프 전체 사이즈 수집 수정

공식 상품: https://smfashion.co.kr/product/detail.html?product_no=4454
품번: DQ1LTS080
검증일: 2026-11-17

기존 크롤러는 option_stock_data에서 is_display=F인 조합을 제외했다.
공홈은 품절 조합에 is_display=F/is_selling=F를 설정하고 현재 선택창에서 제거한다.
이로 인해 품절 색상 및 사이즈가 누락됐으며 색상별 남은 사이즈가 달라
공통 사이즈가 빈칸이 되는 경우도 있었다.

사용자 요청대로 재고/판매/표시 상태와 관계없이 공식 원본 옵션에 등록된
사이즈를 전부 수집한다. 없는 조합은 만들지 않으며 숫자 앞자리 0도 보존한다.
색상별 사이즈가 서로 다른 상품도 수동 매핑 후보별 size를 전달해
최종 색상 행의 사이즈를 유지한다. 사이즈 수집을 해제하면 해당 값은 전달하지 않는다.

실제 수집 결과:
- 블랙(BK), 그린(GN), 핑크(PI), 화이트(WH) 모두 090,095,100,105.
- 완전 품절 핑크와 부분 품절 사이즈도 공식 원본 조합대로 보존.
- 기존 DQ1LTJ007도 실제 worker 재수집과 Excel 생성 통과.
- DQ1LTS080 실제 worker, Excel, 임시 매핑 최종 출력에서 전체 사이즈 유지 확인.
- tests/test_disneygolf.py 7개 통과.

검증용 사진 선택은 별도 임시 폴더에서 수행했고 사용자 작업의 매핑 선택은 변경하지 않았다.
기존 작업 실행 사본은 고정되므로 수정본은 새 작업으로 적용한다.
