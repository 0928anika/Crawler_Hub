# 지프키즈 대백몰 실패 및 추가이미지 5슬롯 수정

검증일: 2026-11-17
구현: `brands/jeepkids_debecmall.py`

## 원인과 변경

- 검색/상세 API는 읽기 타임아웃 한 번으로 전체 품번이 실패했다.
  일시 통신 오류와 HTTP 500/502/503/504에 한해 30초 제한으로 최대 3회 요청한다.
  인증/권한 거부 및 잘못된 응답을 검색 결과 없음으로 바꾸지 않는다.
- 대백몰 상세에 삭제된 이미지와 정상 이미지가 함께 등록되어 있다.
  KO1TSU841의 첫 상세사진은 HTTP/HTTPS 모두 404지만 두 번째 파일은 정상이다.
  404/410으로 확인된 파일만 로그에 남기고 생략하여 정상 상세 원본은 계속 보존한다.
  모든 상세 원본이 삭제됐거나 차단/일시 통신 오류인 경우에는 성공으로 처리하지 않는다.
- 판매자 품번에 `(D.B)`, ` DO`, `VI` 색상 접미사가 있거나
  `KO1THU040/KO1TPU940`, `KO3TSF165/KO3TPF165`처럼 세트 구성 품번이 함께 기재되어 있다.
  지프키즈 브랜드를 확인하고 전체 형식과 실제 구성 품번을 정확히 대조한다.
  유사 품번/부분문자열을 허용하지 않으며 세트 상품명과 가격은 세트 기준으로 유지한다.
- 공식 상세에 `/files//DETAIL/` 이중 슬래시 경로도 존재한다.
  해당 원본 경로를 그대로 인식하며 임의 파일명으로 대체하지 않는다.
- 자동 단일색상 결과는 추가이미지가 1장만 들어가 5슬롯 미완성 경고가 발생했다.
  추가사진 순서를 유지하고 부족한 슬롯은 마지막 유효 사진을 반복한다.
  대표사진 한 장뿐이면 같은 사진을 추가이미지 5칸에 반복한다.
  수동 매핑 최종 출력도 기존 앱의 중복 허용 5슬롯 구성을 확인했다.

## 실제 검증

기존 실패 작업에서 검색 결과 없음 외 원인이 확인된 아래 10개 품번을
수정 크롤러와 기존 Hub worker로 실제 조회하여 모두 Excel 생성에 성공했다.

`KP4TSU854`, `KP3TSU802`, `KO1THU040`, `KO3TPF165`, `KL4PTU792`,
`KO1DPU734`, `KO1TPU998`, `KO1TSU841`, `KO1TZU006`, `KN4PTU774`.

자동 결과 및 수동 매핑 출력 검증용 임시 선택을 합쳐 색상 21행을 확인했다.
모든 최종 행에 추가이미지 5개가 있으며 최종 review_result가 normal이다.
수동 매핑 확인용 선택은 검증 폴더에서만 수행했고 사용자 기존 작업/선택은 변경하지 않았다.

`tests/test_jeepkids_debecmall.py` 13개 통과, 브랜드 등록·코드 해시·문법 검사 통과.
대백몰 검색 자체가 0건인 다른 품번은 이 수정으로 새 상품을 만들어 수집하지 않는다.
기존 작업의 실행 코드는 고정되므로 수정본은 새 작업으로 적용한다.
