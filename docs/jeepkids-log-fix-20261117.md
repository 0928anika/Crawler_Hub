공식 상세 이미지 파일명에 명시된 유일한 품번·색상을 대조한다.
기존 KIDS 분류 검증, 전체 SKU 일치 검증, 이미지 공개 파일 검사는 유지한다.

`KP4TPU098` 및 `KP4TZU098`의 공식 품번 검색은 같은 후드집업 와이드 셋업
MG/CG 페이지로 연결된다. 상세사진에도 상의·하의가 함께 제공된다.
이 두 품번은 확인한 공통 셋업 페이지를 수집하며 상품명·사진·판매가는 셋업 기준이다.
상의/하의 단품 가격으로 분리하거나 다른 임의 품번을 별칭 처리하지 않는다.

색상 정보 행에서 select 전체 텍스트를 색상명으로 사용하지 않는다.
실제 옵션만 추출하고 필수 선택 안내, 구분선, 품절 표시를 제외한다.
공식 한글 색상명이 없고 CG만 있으면 색상=CG, 색상코드=CG, 색상명은 빈칸이다.
코드를 임의로 한글 색상명으로 변환하지 않는다.
