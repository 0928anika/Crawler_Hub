# 패션플러스 통합 · 전체 브랜드

ID: `fashionplus_integrated`. 기존 품목번호/브랜드별 크롤러는 유지한다.

## 수집

사용자는 모델 품번을 입력한다. 전체 브랜드 검색 결과의 상품번호(SKU) 또는 상품명에서 정확한 품번 경계를 검증한다. 모델과 일치하는 모든 판매처의 옵션·가격·판매자·SKU·원본 상세 데이터·썸네일·본문 사진을 수집한다. 스튜디오컷 검사는 하지 않는다. 긴 본문·사이즈·고시 이미지도 후보에 포함한다.

판매자·배송·쿠폰 안내는 URL/alt와 이미지 전체 타일 OCR로 먼저 제외한다. 실제 이미지 읽기가 실패하거나 배너 검사가 완료되지 않은 파일은 성공 후보로 가장하지 않는다.

## 독립된 매핑 두 종류

- 브랜드 카드에 색상 매핑 필요 / 상세페이지 매핑 필요 배지를 함께 표시한다.
- 상세페이지는 `__detail__` 고정 옵션이며 실제 색상 목록과 분리한다. 항상 맨 앞에 표시하고 삭제/수기 추가를 막는다.
- 상세 사진은 선택 순서 목록으로 저장한다. 클릭 후 재선택한 사진은 맨 뒤에 배치한다. 원본 위치 순서로 재정렬하지 않는다.
- 색상 사진은 기존 다중 소유 선택으로 유지한다. 상세 선택 여부는 색상 드래그와 남은 사진 선택에 영향을 주지 않으며 반대 방향도 같다.
- AM 요청의 상세페이지 행은 색상 옵션으로 중복 추가하지 않는다. AM 가져오기/옵션 초기화/색상 삭제는 상세 선택을 보존한다.
- 모든 상세·색상 선택을 저장한 뒤 완료하면 선택한 상세 사진을 순서대로 조합한 공통 HTML이 색상별 결과에 들어간다. 상세페이지 자체를 색상 결과 행으로 출력하지 않는다.

## 확인

실제 IF95NSEJ6230에서 썸네일과 본문의 사진 후보 10장을 확인했다. 별도 로컬 서버에서 상세 사진 선택 순서 표시, 색상과 독립된 선택, AM 가져오기 시 고정 옵션 유지 및 최종 XLSX의 HTML 순서를 검증했다.

새 크롤러와 UI를 적용하려면 앱을 재실행하고 새 작업으로 수집한다. 기존 크롤러에는 새 상세 옵션을 추가하지 않는다.
